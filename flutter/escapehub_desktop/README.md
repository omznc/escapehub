# EscapeHub desktop

The staff application of EscapeHub for the roles `Administrator` and `RoomManager`.
A `Client` account cannot sign in.

## Run

1. Start the API on `http://localhost:5000`.
2. Run `flutter pub get`.
3. Run `flutter run -d windows` or `flutter run -d linux`.

To use a different API address, add `--dart-define=API_BASE_URL=<url>`.
